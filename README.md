# RCT2.js — 用 Three.js 复刻 OpenRCT2

一个开箱即玩的浏览器版过山车大亨(向 [OpenRCT2](https://github.com/openrct2/openrct2) 致敬)。所有美术资源均为程序化生成的低多边形 3D,无版权素材。支持**多人联机共同经营同一座公园**。

## 运行

```bash
npm install           # 首次(ws + 测试用 playwright)
node serve.mjs        # 然后打开 http://localhost:8765
```

`node serve.mjs` 同时提供游戏页面与多人服务器:任何玩家打开该 URL、选择"多人联机",就会进入**同一座共享公园**。局域网游玩直接把链接发给同伴即可。

联机公园由服务器自动保存到 `park-save.json`(每个游戏月)。重置联机公园:

```bash
RESET=1 node serve.mjs
```

## 玩法

从入口开始修路 → 建设施 → 开放,吸引游客,经营收支,提升公园评分。

- **目标**:沙盒经营默认带一组达标目标;也可在**开始页或关卡面板(奖杯图标)选择关卡**——8 个剧本顺序解锁(游客数/评分/限时,另有现金大考)。单人关卡开始时自动切换专属地图与起始资金。达成/失败/破产(现金跌破 -$4,900)都会弹出**结算面板**:继续沙盒、重玩本关或进军下一关。通关按完成早晚授予**金/银/铜奖杯**(≤55% 期限得金),最佳记录持久化并在关卡面板展示。
- **单人存档**:3 个存档位(自动每 2 个游戏月保存到当前档位),档位显示年份/设施数;旧版单存档自动并入 1 号位。
- **多人模式**:全部玩家共享同一笔资金与同一座公园;建造/拆除/调价广播同步;游客、过山车列车、经济按月结算由服务器权威模拟;带在线名单与聊天(联机面板,工具栏双人图标);客户端也能看到乘坐设施中的游客(快照带设施 id,按本地动画位姿绘制)。
- **游戏速度**:工具栏双三角按钮在 1×/2×/4× 间切换(仅单机;联机由服务器控制)。
- **昼夜循环**:180 秒一轮(120s 白天 + 60s 夜晚,各 15s 晨昏过渡),夜间阳光/环境光渐暗、天空转深蓝,路灯亮起暖色光点。
- **音效**:WebAudio 程序合成,零素材——按钮点击、建造放置/拆除、失败提示、收银(节流)、研发完成、通关/失败号角;**人群尖叫**(高强度设施满载运转、过山车俯冲时触发)、轨道轰鸣、提升坡链条咔嗒;**环境音**:雨声随天气、人群嘈杂随游客密度、旋转木马八音盒(原创圆舞曲音型)随镜头距离;工具栏喇叭图标一键静音(记忆设置)。原版 RCT2 音频为版权素材,本作一律合成近似,不使用原作资源。
- **第一视角**:游客面板的"第一视角游览"随机跟随一位游客,透视相机贴地游园;左键拖动环视,`Esc` 退出;游客上车/离园自动换下一位(联机也可用)。
- **开发者控制台**:工具栏 `>$_` 图标——印钱、一键完成所有研究(联机下经服务器广播生效)。

## 操作

| 操作 | 按键/手势 |
| --- | --- |
| 平移视角 | 右键(或中键)拖拽 / WASD / 方向键 |
| 旋转视角(4 向) | `Q` / `E` 或工具栏旋转按钮 |
| 缩放(3 档) | 滚轮(围绕光标缩放)或工具栏 +/− |
| 取消当前工具 | `Esc` |
| 第一视角环视/退出 | 左键拖动 / `Esc` |
| 暂停 | 工具栏暂停按钮 |

### 工具栏(从左到右)

- **存档**:保存/读取/新的公园(联机下为只读说明)
- **整地**:抬升 / 压低 / 整平,1×1 至 5×5 笔刷,按住拖动连续作业(按面积计费)
- **景观**:松树/阔叶树/红枫/白桦/灌木/花丛
- **路径**:主路(带白边)、排队通道(蓝色+栏杆);主路上可加装长椅/路灯/垃圾桶;拆除模式可回收
- **园区地图**:俯瞰小地图(水/草/沙/路/设施),点击跳转视角
- **游乐设施**:旋转木马、摩天轮、旋转飞椅、鬼屋、碰碰车、海盗船、观光塔、螺旋滑梯、旋转茶杯、飞天秋千、跳楼机、大摆锤、太空梭、迷宫、迷你高尔夫、**观光缆车**(两站台索道,吊舱往返,两端各自排队上下客)、**脚踏船**(邻水码头,小船湖上漫游到点返航)、**预制木制过山车**、**定制过山车 / 观光小火车 / 悬挂单轨 / 激流勇进**(轨道编辑器逐段搭建,见下)
- **商店**:汉堡(解饿)/饮料(解渴)/纪念品(开心度,气球)/咖啡(提神)/厕所(内急)/伞具店(雨天卖伞,游客打伞)
- **游客 / 财务 / 公园信息**:游客想法流、贷款(借还+月息)、门票调价、剧本目标状态、天气显示、园区开放闸;游客面板可进**第一视角**
- **点选小人查看状态**:空工具下左键点游客/员工弹出状态窗(游客:开心/饥饿/口渴/体力/内急/晕眩与现金;员工:岗位与工作状态),实时刷新,离园自动关闭
- **设施内可见游客**:游客乘坐旋转木马(骑木马/站台)、摩天轮座舱、飞椅吊舱、碰碰车、海盗船座位、观光塔环舱、过山车车厢、鬼屋内部时,人随设施一起运动
- **员工辨识**:员工一律戴白色工作帽(游客为棕发),制服色区分岗位

### 设施经营

- 放设施需要**平整地面**;不再强制紧邻路径——可以先放好,再用设施窗口的**设入口/设出口**工具点选设施边缘任一临路格来接驳(联机同步)。
- 入口未接通路径时设施**不能开放**(测试模式不受限)。
- 点已建好的设施打开设施窗口:关闭/测试/开放、调票价、设出入口、查看客量与收入、定位、拆除(返还 55%)。
- 游客走到设施门口会按票价与心情决定是否排队;队满会放弃。

### 轨道编辑器(定制过山车 / 观光小火车 / 激流勇进)

- 游乐设施面板选三种定制设施之一 → 选好站台朝向 → 地图点击放站台,进入逐段铺轨。
- 轨道件按风格:**过山车**=平直/提升坡(链条匀速)/上坡/下坡/陡坡(±2 层)/左右弯/刹车/立环/螺旋翻滚;**小火车/悬挂单轨**=平轨/弯道/沿线可加站台,匀速巡游**逐站停靠**(单轨为高架梁悬挂车厢);**激流勇进**=水槽平直/提升坡/俯冲/弯道,漂流物理。按段计费;支持撤销上一段(返 55%)、放弃拆除。
- **多列车**:轨道采样 ≥36 时自动上第二列车,简单闭塞保持车距、站台被占时排队等候。
- **自动闭环**:编辑器一键搜索回路(A* 按世界约束搜索平直/上下坡/弯道组合),确认后自动铺回站台。
- 每段实时校验:公园范围内、地形不阻挡、不自交(同格需 2 层净空)、跨路径需净空 ≥1.7;轨道自动生成立柱支架(高支架为 A 形双柱;水槽可跨水面)。
- 轨道接回站台即**可闭环**,建成后由落差/弯数/长度按风格估算兴奋度/强度/晕眩;设出入口、开放、定价与预制版一致;过山车与水槽俯冲触发尖叫+轰鸣,提升坡有链条声。
- **多站台**:小火车沿线可放多个站台(同风格件集里的"站台"件),每站自动识别临路门位;游客在各站分别排队,上车随机选后续站下车,列车逐站停靠上下客。
- 联机全程同步(铺轨动作经服务器广播);存档/联机公园均保存轨道件。

### 设施涂装与改名

- 设施窗口可**改名**(16 字内,随存档/联机同步)与**整体涂装**(8 色,含默认白);轨道设施加段重建后涂装保持。

### 设施老化与翻新

- 设施每月累积园龄:兴奋度随园龄衰减(约 22 个月到 55% 下限),老化设施更容易故障;设施窗口可**翻新**(造价 35%,园龄归零、可靠度回满、顺带修好故障)。

### 购地扩建

- 整地面板新增**购地**:购买与公园相邻的 3×3 地块($30/格),小地图即时更新。

### 员工巡逻区

- 员工面板每人可**划区**:地图上两次点击框选矩形,员工只在区内漫游/接任务(出区自动走回);随时一键恢复全园巡逻;巡逻区随存档保存。

### 成就与引导

- 8 个成就(开放首个设施/游客规模/累计接待/现金/研发全满/定制轨道/剧本达成),达成时消息+号角,公园信息面板可查看进度,localStorage 持久化。
- 首次开局有新手指引消息;设置面板(齿轮图标)含音量滑块、静音、按键说明;移动端支持单指平移、双指捏合缩放。
- **通知中心**(铃铛图标):最近 22 条消息列表,设施相关消息点击直达设施窗口。
- **天气预告**:公园信息面板显示下月天气(上月月结时预掷)。
- **评分曲线**:公园信息面板的折线图(每月采样,联机客户端本地采样)。
- **性能档位**:设置面板可调游客上限(120/180/260)与画质(高=设备像素/低=1×)。

### 研发

- RCT2 经典研发:初始只可建旋转木马与汉堡店,其余(饮料店→摩天轮→纪念品店→旋转飞椅→木制过山车)需研发解锁。
- 研发面板(工具栏烧瓶图标)可设经费档位:**无 / 最小 $100/月 / 普通 $200/月 / 最多 $400/月**,月结扣款;进度满即解锁并滚动通知。
- 研发状态单机/联机都会保存;联机由服务器权威推进,经费档位全员共享。

### 员工

- 三种岗位(工具栏扳手图标雇用):
  - **清洁工**:游客会丢垃圾、眩晕值高时会呕吐;垃圾降低评分与心情;清洁工自动寻路清扫。**垃圾桶**有容量(8 次),满了要清洁工来倒。
  - **维修工**:设施有可靠度,运营中缓慢下降,可靠度低会**故障停摆**(甩客+不能排队);维修工自动前往修复,也会定期检修低可靠度设施。可靠度/故障在设施窗口可见。
  - **演艺人员**:半径振奋光环,附近游客(含排队中)开心度持续回升。
- 月薪 $60/$90/$50,月结计入"工资";员工面板可定位/解雇;联机全员共享、同步可看。

## 游客 AI

游客在路径网络上随机漫游(接近 RCT2 的路口随机行为),有饥饿/口渴/体力/内急/开心度五维需求,外加晕眩与天气(下雨没伞不开心);饿了找汉堡店、内急找厕所、下雨买伞打伞、暴怒砸长椅;乘坐设施影响心情,过山车按简化势能物理运行(提升坡匀速 + 重力加速 + 弯道倾斜)。游客会把即时想法(饿/渴/想吐/太贵/要伞)送进"游客想法"流。

**家庭组与偏好**:游客按 1~5 人的家庭组入园(成人 1~2 人 + 儿童),同组成员跟随领队漫游;儿童体型更小、现金更少、刺激偏好低(强度 >55 的设施不玩)。每位游客有固定的刺激偏好,与设施强度匹配决定是否排队(对同一设施决定稳定,不会反复横跳),合口味的设施下车后开心加成更高。点选游客可见其类型/偏好/家庭组,游客面板有家庭组与儿童统计。

## 天气

晴/阴/雨每月随机轮转(服务器/单机权威)。下雨:光照变暗、雨幕粒子、游客少来、没伞双倍掉开心度、伞具店热卖。全部联机同步。

## 多人架构

- **服务端权威模拟**:`server/simhost.js` 在 Node 里 headless 运行与客户端完全相同的游戏逻辑(世界/路径/设施/游客/经济),15Hz 模拟、6Hz 快照广播。
- **动作协议**:所有改世界操作抽象为动作(`src/game/actions.js`),单机本地执行,联机经 WebSocket 由服务器验证+从共享资金扣钱后按序广播 —— 所有客户端以同一顺序复现同一世界变更,天然一致。
- **快照同步**:游客位置/外观/气球、过山车列车状态(弧长/模式)、经济数据(现金/评分/日期)周期推送,客户端插值渲染。
- 耐久性:公园每月自动存为 `park-save.json`;服务器重启自动恢复。

## 技术要点

- **Three.js r160**,正交等距相机(30° 俯仰,45° 四向方位),三档缩放平滑过渡
- **地形模型完全采用 RCT2 的角点坡度编码**:每 tile 一个 base 高度 + 4bit 坡面掩码;相邻高差自动生成挡土墙/悬崖面
- 地形 25×25 tile 分块重建;树木/游客全部 `InstancedMesh`(游客全身仅 6 次 draw call)
- 全部纹理为 canvas 程序化生成;UI 为 HTML/CSS 仿 RCT2 铁板灰窗口

## 与原作相比

有的:等距四视角/三档缩放、角点坡地、整地计费、白边主路+蓝色排队通道+栏杆、长椅路灯垃圾桶、树木花草、平地设施、预制过山车、**可逐段搭建的定制过山车(轨道编辑器)**、可设出入口、研发解锁、**员工系统(清洁工/维修工/演艺/保安、垃圾/呕吐、垃圾桶容量、设施可靠度故障)**、游客需求与排队、门票票价、月度结算、公园评分、存档、**多人共同经营**、**程序合成音效**、**关卡剧本(6 关顺序解锁)**、**游客第一视角**。

没做(将来可扩展):过山车立环/螺旋等高级轨道件与多列车、动植物/主题包装套件、自定义风景组合、原作库存档导入、分房间/权限管理、破产保护。
